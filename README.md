# Chamuyados

Proyecto creado en React para la Actividad 3. Es un juego de preguntas inspirado en Preguntados, pero centrado en chamuyo, citas y vínculos.

## Componentes principales

- `app/page.tsx`: componente principal y estado del juego.
- `components/Header.tsx`: logo, puntaje y vidas.
- `components/GameCard.tsx`: pregunta, categoría, progreso y devolución.
- `components/AnswerButton.tsx`: botón reutilizable para cada respuesta.
- `components/Footer.tsx`: pie de página.

## Cómo ejecutarlo

1. Abrir la carpeta en Visual Studio Code.
2. Abrir una terminal y ejecutar `npm install`.
3. Ejecutar `npm run dev`.
4. Abrir la dirección que aparece en la terminal.

El proyecto incluye una interacción básica: permite elegir una respuesta, informa si es correcta, modifica el puntaje o las vidas y avanza a la pregunta siguiente.
