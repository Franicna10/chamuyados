# Presentación breve · Chamuyados

## Guion sugerido (aprox. 1 minuto)

“Chamuyados es un juego web de preguntas sobre chamuyo, chats, primeras citas y vínculos. La persona juega una ronda Solo de diez situaciones y clasifica cada una como Chamuyo, Red flag o Green flag. Hay siete categorías, incluida Modo íconos argentinos, con situaciones originales.

La partida completa dura 60 segundos: el reloj sigue durante las preguntas y las devoluciones. Cada acierto suma 100 puntos y después de responder aparece una explicación breve. Al final se muestran aciertos, errores, preguntas sin responder, promedio y rango. Las partidas se guardan en el navegador para construir un ranking local.

La aplicación está hecha con React, TypeScript, Vite y React Router. La navegación tiene rutas propias para inicio, perfil, ayuda, ranking, categorías, pregunta, devolución y resultado. La prueba externa, el despliegue en Vercel y la publicación de Instagram quedan como pasos de entrega.”

## Orden sugerido para la demo

1. Mostrar el inicio y la ayuda.
2. Crear el perfil, elegir Solo y recorrer las categorías.
3. Responder una situación y mostrar la devolución.
4. Mostrar el resultado y el ranking local, si ya se completó una partida.
5. Explicar el estado real de prueba y despliegue sin presentarlos como completados si siguen pendientes.
